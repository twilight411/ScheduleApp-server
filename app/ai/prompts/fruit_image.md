请根据用户过去一个月的数据生成一个象征"本月能量高点"的果实图像。

<input>
你将获得五个生活方向的月度评分 (0-10) 以及用户本月的具体行为记录。
请找出评分最高的方向, 并根据该方向对应的真实行为生成一个个性化、象征性的果实造型。
此外可能附加「月度基调」信息, 描述用户本月最常出现的优先方向 (例: "3 周备考")。
</input>

<core_rule>
果实必须来源于用户本月真实行为, 而不是固定图标。
</core_rule>

<examples>
- 兴趣方向最高且本月多次打羽毛球   → 果实可以是抽象化的羽毛球形态
- 工作学习最高且本月写论文较多     → 果实可以是简化的书页、键盘或文档形态
- 健康最高且频繁运动               → 果实可以呈现跑鞋轨迹或运动器械的抽象形态
- 社交最高且多次聚餐               → 果实可以是抽象化的气泡或对话框形态
- 娱乐最高且看了多部电影           → 果实可以是胶片或屏幕光晕的抽象形态
</examples>

<design_requirements>
- 造型: 象征化、简化、扁平化, 不写实描绘
- 果实品质由月度评分决定: 评分越高果实越华丽 (发光 / 纹理丰富 / 色彩饱满)
- 果实上可融入本月关键行为的微缩元素
</design_requirements>

<monthly_focus_influence>
果实的「内核纹理」由本月基调决定 (基调影响纹理 / 材质, 不改变果实整体造型方向, 造型仍由最佳维度决定):

- 备考月       → 果实内里隐约有书页、字迹、纸张的纹理
- 项目冲刺月   → 果实表面有简洁的几何切线或文档符号
- 健康月       → 果实表皮有汗珠光泽或运动质感
- 社交月       → 果实周围有气泡或对话框元素
- 兴趣月       → 果实融入用户具体兴趣的微缩元素
- 混合月 (多种基调切换) → 五色渐变或层次切片感, 表达月内的转换
- 平衡月 (未设重点)     → 果实表面纹理平和均衡, 五色微妙过渡
</monthly_focus_influence>
